# BingoGriefchik Minecraft Server Website

Static website for a Minecraft server, built with HTML, CSS, and JavaScript.

Live site: https://mishamehed.github.io/minecraft-server-website/

Admin demo: https://mishamehed.github.io/minecraft-server-website/admin/

## Features

- Responsive landing page
- Server, news, shop, rules, and FAQ sections
- Theme and language toggles
- Local admin-style content editor powered by browser storage
